# suhek7.github.io

Personal profile site, live at https://suhek7.github.io. Plain HTML and CSS on GitHub Pages: no framework, no build step.

## Why this site exists

A resume says what you did. A profile site says how you think. This site exists to answer the question a hiring leader actually has in the first thirty seconds: what has this person run, at what scale, and what is his point of view?

That is the differentiator: perspective over inventory. Instead of a wall of skills, it leads with proof (10+ years in BFSI, a 100+ FTE delivery pipeline, 60+ automations implemented), then an approach section, then one flagship project - an AI-powered control-testing tool - that shows how he thinks about AI in production, not just that he has used it.

Everything else - the experience timeline, certifications, the resume download - is garnish on that one first impression.

The same repo also hosts the Infosys Bangalore campus tree map at [/trees](https://suhek7.github.io/trees/).
